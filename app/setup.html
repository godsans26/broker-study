동기화 서버 연결

문제풀이는 서버 없이 사용할 수 있습니다. 여러 기기의 학습 기록을 공유하려면 아래 설정을 한 번 진행하세요.

  1. Supabase에서 프로젝트를 만듭니다.
  2. SQL Editor에서 저장소의 supabase/schema.sql 전체를 실행합니다. 계정별 접근 제한과 기록 병합 함수가 생성됩니다.
  3. Authentication → URL Configuration에 앱 주소 https://godsans26.github.io/broker-study/를 Site URL 및 Redirect URL로 등록합니다.
  4. 프로젝트 URL과 publishable 키(또는 legacy anon 키)를 확인합니다. secret/service_role 키는 사용하지 않습니다.
  5. GitHub 저장소 Settings → Secrets and variables → Actions → Variables에서 SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY를 등록하고 Actions의 Deploy study app 워크플로를 다시 실행합니다. 공개용 설정이 앱에 포함됩니다. 임시로 앱의 ‘동기화 → 서버 연결’에 입력해 기기별로 설정할 수도 있습니다.
  6. 앱에서 이메일로 계정을 만들고 확인 메일이 오면 링크를 누릅니다. 각 기기에서 같은 계정으로 로그인합니다.
  7. 기존 기록은 같은 문제집에서 JSON으로 불러오거나 ‘로그인 전 이 기기 기록 합치기’를 누릅니다.

동기화되는 내용

답변·헷갈림 표시·풀이 위치·학습 범위를 공유합니다. 서로 다른 문제의 답변은 합치고, 같은 항목을 여러 기기에서 바꾸면 기록의 논리 시각과 기기 식별자로 순서를 정합니다. 두 기기의 시계 차이가 크면 화면에서 수정한 순서와 다를 수 있습니다.

‘다시 풀기’로 삭제한 답변도 변경 기록으로 전달합니다. 오프라인 기록은 인터넷에 연결하고 앱을 열면 재전송됩니다. 앱을 종료한 상태의 백그라운드 동기화는 보장하지 않습니다.

계정마다 기록이 분리됩니다. 로그아웃 후에도 이 기기에는 계정별 기록이 남습니다. 공유 기기에서는 사용 후 브라우저의 사이트 데이터를 지우세요.
